Introduction

VioTools API provides watermark removal over standard HTTP with JSON responses. Images run synchronously; videos use asynchronous jobs.

Base URL
https://viotools.my.id/api/v1
Use only media you own or have permission to modify. Never expose an API key in client-side code or public repositories.

Authentication

Every request requires your key in the X-API-Key header.

X-API-Key: YOUR_API_KEY

Get a key from the VioTools dashboard. Treat it like a password.

Quick start

Check authenticated API readiness.

curl https://viotools.my.id/api/v1/health \
  -H "X-API-Key: YOUR_API_KEY"
Response · 200
{
  "status": "ok",
  "service": "veo-watermark-api",
  "version": "1.0.0"
}

POST/remove/image

Remove a watermark from an image synchronously.

FieldTypeRequiredDetails
imagemultipart fileYESPNG, JPG, JPEG, WEBP · max 20 MB
curl -X POST https://viotools.my.id/api/v1/remove/image \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "image=@/path/to/image.png"
Response
{
  "success": true,
  "downloadUrl": "/api/v1/download/file_processed.png",
  "filename": "file_processed.png"
}

POST/remove/video

Upload a video and start an asynchronous removal job.

FieldTypeRequiredDetails
videomultipart fileYESMP4, MOV, MKV, AVI · max 500 MB
curl -X POST https://viotools.my.id/api/v1/remove/video \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "video=@/path/to/video.mp4"
Response
{
  "success": true,
  "jobId": "abc123-def456",
  "statusUrl": "/api/v1/status/abc123-def456"
}

POST/remove/video-url

Process a public HTTP(S) video URL directly.

FieldTypeRequiredDetails
urlstringYESMP4/MOV/MKV/AVI URL · max 500 MB
curl -X POST https://viotools.my.id/api/v1/remove/video-url \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/video.mp4"}'

GET/status/:jobId

Poll until status is completed or failed.

curl https://viotools.my.id/api/v1/status/JOB_ID \
  -H "X-API-Key: YOUR_API_KEY"
Completed response
{
  "jobId": "abc123-def456",
  "status": "completed",
  "progress": 100,
  "downloadUrl": "/api/v1/download/output.mp4"
}

GET/jobs

List jobs owned by this API key.

QueryRequiredDetails
statusNOprocessing, completed, failed
limitNODefault 20 · max 100
offsetNODefault 0
curl "https://viotools.my.id/api/v1/jobs?status=completed&limit=20" \
  -H "X-API-Key: YOUR_API_KEY"

GET/download/:filename

Download a processed file. Keys access only files they own.

curl -L -o cleaned.mp4 \
  https://viotools.my.id/api/v1/download/FILENAME \
  -H "X-API-Key: YOUR_API_KEY"

Webhooks

Receive job.completed and job.failed without polling.

Register · POST /webhooks

curl -X POST https://viotools.my.id/api/v1/webhooks \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://yourapp.com/hook",
       "secret":"WEBHOOK_SECRET",
       "events":["job.completed","job.failed"]}'

Manage

GET/webhooks   List registrations

DELETE/webhooks/:id   Delete registration

If a secret is set, verify X-Webhook-Signature using HMAC-SHA256 over the raw request body.

GET/usage

View request counts, daily limit, and remaining quota.

curl https://viotools.my.id/api/v1/usage \
  -H "X-API-Key: YOUR_API_KEY"
Response
{
  "total": 42,
  "today": 3,
  "limit": 100,
  "remaining": 97,
  "window": "24 hours"
}

MCP server

Connect VioTools to Claude Desktop or another Model Context Protocol client.

remove_image_watermarkClean a local image.
remove_video_watermarkUpload, poll, download.
remove_video_watermark_urlProcess a public URL.
check_job_statusCheck an async job.
list_jobsList recent jobs.
get_usageRead quota usage.

{
  "mcpServers": {
    "viotools": {
      "command": "node",
      "args": ["/absolute/path/mcp-server/index.js"],
      "env": {
        "VEO_API_BASE": "https://viotools.my.id/api/v1",
        "VEO_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}
